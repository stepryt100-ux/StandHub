StandHub — запуск
1. Установите Node.js 18+ (https://nodejs.org).
2. В папке standhub выполните:  node server.js
3. Откройте http://localhost:3000

Онлайн = реальное число людей с открытым сайтом (считаются уникальные посетители).
Аккаунты и матчи хранятся в data/db.json (создаётся автоматически).
Рейтинг показывает только игроков, сыгравших хотя бы 1 матч.

Матчи: очередь 5 на 5 / 2 на 2 / 1 на 1 → «Матч найден» (15 сек) → вето карт капитанами → игра у хоста →
капитан отмечает результат («Мы победили» / «Мы проиграли», через 10 минут после начала) → соперники подтверждают
или оспаривают (30 минут, потом результат засчитывается сам) → ELO пересчитывается. Логика — в match.js.
Спор решает админ в разделе «Админ»; доказательства (видео, скриншоты) игроки присылают Telegram-боту —
бот пересылает их администраторам (proofs.js), на сайте файлы не хранятся.
Администратор по умолчанию — Kartez. Чтобы изменить: Railway → Variables → ADMIN_NICKS = ники через запятую.
Админ видит раздел «Админ» (спорные матчи) и кнопку «Тестовый матч с ботами» в лобби.

Монеты и магазин: монеты дают ежедневные задания и бонус за вход (tasks.js). В «Магазине» (shop.js) монеты
меняются на товары — сейчас это промокод на 1000 голды. Промокод выдаёт администратор вручную: после покупки
игрок получает заказ с номером (№1001, №1002…) и пишет в Telegram @swupliq со скриншотом заказа (или пересылает
сообщение бота). В «Админ» → «Магазин» видны заказы (ник игрока на сайте и его Telegram), их можно отметить
«Выдан» или отменить с возвратом монет. Там же меняются цена, лимит покупок в неделю, количество в наличии
(пусто — без ограничения), «продаётся/нет» и ник, кому писать. О каждой покупке админу приходит сообщение.
В игре код вводится так: главный экран StandLeo → «События» → «Секретный код».
